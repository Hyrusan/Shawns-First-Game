## Event Card Seeds

### Travelling Bard

Choices:

| Choice | Result |
| --- | --- |
| Hire them | Gain morale, spend gold |
| Ignore them | No effect |
| Challenge them | Possible fame or embarrassment |

### Dragon Attacks Nearby Villages

Choices:

| Choice | Result |
| --- | --- |
| Send strongest team | High risk, high fame |
| Pay the guards | Lose gold, reduce damage |
| Hide | Lose fame |

### Adventurer Wants To Retire

Choices:

| Choice | Result |
| --- | --- |
| Let them retire | Gain legacy bonus |
| Convince them to stay | Risk loyalty loss |
| Offer partnership | Unlock council role |
